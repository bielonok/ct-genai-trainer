# CT-GenAI Тренажёр

Тренажёр для подготовки к экзамену ISTQB® Certified Tester – Testing with Generative AI (CT-GenAI v1.1).
Открывается как отдельное приложение (PWA), работает офлайн, а прогресс синхронизируется между устройствами после входа по email.

Адрес после публикации: **https://bielonok.github.io/ct-genai-trainer/**

## 1. Включить GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
Через 1–2 минуты сайт откроется по адресу выше.

## 2. Установить на телефон

- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## 3. Синхронизация прогресса (Supabase, бесплатно)

Пока в `config.js` нет ключей, приложение полностью работает, но прогресс хранится только на этом устройстве.

1. Зарегистрируйтесь на https://supabase.com → **New project** (регион поближе, например Frankfurt). Пароль базы данных сохраните в надёжном месте, для тренажёра он не понадобится.
2. **SQL Editor** → New query → вставьте содержимое `supabase.sql` → Run. Будет создана таблица `progress`, каждый пользователь видит только свою строку.
3. **Authentication → URL Configuration:**
   - Site URL: `https://bielonok.github.io/ct-genai-trainer/`
   - Redirect URLs: добавьте тот же адрес.
4. **Authentication → Emails (шаблоны) → Magic Link:** добавьте в текст письма код `{{ .Token }}`, например строку `Ваш код: {{ .Token }}`.
   Это важно для телефона: установленное приложение на iPhone не получает вход по ссылке из письма, поэтому нужен код, который вводится вручную.
5. **Project Settings → API** (или кнопка **Connect**): скопируйте **Project URL** и **anon / publishable key** и вставьте их в `config.js`:
   ```js
   window.SB_CONFIG = {
     url: 'https://xxxx.supabase.co',
     anonKey: 'eyJ...'
   };
   ```
   Anon-ключ публичный, его безопасно хранить в репозитории: данные защищены правилами RLS из `supabase.sql`.
6. В приложении нажмите **🔑 Увійти** → введите email → введите код из письма. Статус должен смениться на «☁️ Синхронізовано».
7. *(По желанию)* После того как вы вошли, отключите регистрацию новых пользователей в Authentication → Sign In / Providers («Allow new users to sign up»), чтобы посторонние не создавали аккаунты в вашем проекте.

> Названия пунктов меню Supabase время от времени меняются. Если чего-то не нашли, ищите по смыслу: URL Configuration, Email Templates, API keys.

## 4. Перенос прогресса из версии на claude.ai

Дашборд → «Експорт / імпорт» → «Копіювати» в старой версии → в новой версии «Експорт / імпорт» → вставить → «Імпортувати».

## Обновления

Когда добавляются новые главы, заменяется только `index.html`. Приложение подхватит новую версию при следующем открытии с интернетом. Прогресс при этом сохраняется.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Тренажёр целиком (HTML + CSS + JS, без внешних зависимостей) |
| `config.js` | Ключи Supabase для синхронизации |
| `manifest.webmanifest`, иконки | Установка как приложения |
| `sw.js` | Офлайн-режим |
| `supabase.sql` | Таблица и правила доступа |

Материалы основаны на ISTQB® CT-GenAI Syllabus v1.1 и Sample Exam A v1.1 (© ISTQB®), используются для некоммерческой самоподготовки.

## Для разработки

Исходники лежат в `src/`: `engine.js` (схемы), `app.js` (логика), `shell.html` (разметка и стили), `ch1_*.js` (контент главы 1).
Новая глава добавляется файлами `src/ch2_*.js` с блоком `chapters[2] = {…}`. После правок запустите `python3 build.py`: скрипт пересоберёт `index.html` (PWA) и `dist/ct-genai-trainer.html` (единый офлайн-файл).
При каждом изменении поменяйте `CACHE` в `sw.js` (например, `ctgenai-v2`), чтобы установленное приложение точно обновилось.
